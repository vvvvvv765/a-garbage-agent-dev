# 第三方许可

## DeepSeek Harness

- 使用范围：Web UI 继续使用 `WebUI/static/dsh/marked.esm.js` 进行 Markdown 解析；对话与工具界面的 CSS 主题已改为 Spirit 自有样式，不再加载 `dsh/theme.css`、`dsh/vendor.css`、`dsh/app.css`。
- 许可：随项目保留的 `WebUI/static/dsh/LICENSE`（MIT）；分发时保留该许可文件。

## cc-switch

- 项目：https://github.com/farion1231/cc-switch
- 使用范围：`WebUI/static/provider-presets.js` 的供应商地址、接口协议（Anthropic / Chat / Responses）、认证方式（`ANTHROPIC_API_KEY` → x-api-key、`ANTHROPIC_AUTH_TOKEN` → Bearer）、模型清单与分类，照抄 `src/config/claudeProviderPresets.ts`（2026-11 版本，141 条）；分类栏（账号登录 / 模型厂商 / 第三方平台 / 云服务商 / 本地）与 2 列卡片布局照 `src/components/providers/forms/presetGroups.ts` 与预设选择器页面；`WebUI/static/provider-icons/` 的供应商图标来自 `src/icons/extracted/`。
- 2026-11-19 追加（v4.0.35）：OpenCode 网关的会话头规则照抄 `src-tauri/src/proxy/forwarder/opencode.rs`——`x-opencode-session`（每会话稳定）+ 自己的 User-Agent（不能是 SDK 默认名），Spirit 由适配层在目标为 `opencode.ai` 时补上；会话 id 改用 Spirit 自己的算法（第一条用户消息的 sha256 前 32 位）。
- 2026-11-19 追加（v3.18.0）：供应商管理的**行为判定**照抄 cc-switch——连通性测试（任意 HTTP 响应即可达、TTFB 6 秒分档，`src-tauri/src/services/stream_check.rs`）、端点测速（预热一次 + 计时一次、超时 2–30 秒钳制，`src-tauri/src/services/speedtest.rs`）、余额查询模板（`src-tauri/src/services/balance.rs` 的 DeepSeek / OpenRouter / SiliconFlow / Moonshot 地址与字段）、拖拽排序与 `sortIndex`、分类 / 优先级徽章、故障转移队列与熔断参数（连续 4 次失败、冷却 60 秒，`proxy/circuit_breaker.rs`）。Spirit 侧按自身架构重写（Python，去掉了需要本地代理 / OAuth / 外部配置文件的部分）。
